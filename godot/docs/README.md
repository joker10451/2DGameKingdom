# Документация проекта: «Хроники Олдерии: Живой Мир»

Вся проектная документация структурирована по специализированным разделам:

1. **[PITCH_DOCUMENT.md](file:///e:/kiro/game/godot/docs/PITCH_DOCUMENT.md)**
   * Краткий концепт-документ (Producer One-Pager).
   * Логлайн, целевая аудитория, ключевые USPs, игровой цикл и анализ конкурентов.

2. **[LORE_AND_WORLD_BIBLE.md](file:///e:/kiro/game/godot/docs/LORE_AND_WORLD_BIBLE.md)**
   * Полная библия мира Олдерии.
   * История («Ночь Семи Баронов»), 4 региона, фракции, секрет тигельной стали («Синий Чугун»), правовые обычаи (Вергельд), биографии ключевых личностей и темная тайна («Заговор Зачумленного Зерна»).

3. **[GAME_DESIGN_DOCUMENT.md](file:///e:/kiro/game/godot/docs/GAME_DESIGN_DOCUMENT.md)**
   * Полный геймдизайн-документ.
   * Механики всех ролей (крестьянин, купец, бандит, лорд, монарх), математические формулы Utility AI и динамического рынка, 2-уровневая архитектура LOD-симуляции в Godot 4.

4. **[RACES_XENOBIOLOGY.md](file:///e:/kiro/game/godot/docs/RACES_XENOBIOLOGY.md)**
   * Ксенобиологический справочник нечеловеческих рас.
   * Жильники (Кхерн) — подземные рудознатцы, слышащие руду через камень.
   * Тростянки (Мховь) — болотные алхимики, чующие ложь по запаху пота.
   * Сводная таблица баланса рас для игрового процесса.

5. **[RANDOM_EVENTS_TABLE.md](file:///e:/kiro/game/godot/docs/RANDOM_EVENTS_TABLE.md)**
   * Таблица из 10 случайных событий мира с моральными выборами, расследованиями и каскадными последствиями.
   * Правила системы: частота, контекстная привязка, симметричность (события происходят и с NPC), память мира.
