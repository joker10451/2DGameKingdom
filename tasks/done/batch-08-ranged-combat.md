# Task: Пакет №8 — Стрельба из Лука, Дальний Бой и Враги-Стрелки (Ranged Combat & Archery)

## Цели пакета:
1. **🏹 Луки, стрелы и баллистика полета**:
   - Охотничий лук, длинный ясеневый лук, оперенные стрелы.
   - Выстрел на ЛКМ по направлению курсора мыши, полет снаряда с наконечником и оперением.
2. **🎯 Навык «Стрельба из лука» в Книге Навыков [ K ]**:
   - Расчет урона, дальности и перков «Орлиный глаз» и «Бронебойный наконечник».
3. **🦹‍♂️ Враги-стрелки с дистанционным ИИ**:
   - Лесные разбойники-лучники и скелеты-лучники с кайтингом (отступают при сближении).
   - Блокирование стрел щитом на ПКМ.
4. **🪚 Крафт стрел и луков на верстаке плотника**:
   - Производство стрел из дерева и руды.
