# GDD — «Бабушкина дача»

> Статус: заглушка. Документ заполняется итеративно по мере задач.

## Оглавление

1. **Концепция** — казуальная игра: merge предметов + обустройство дачи. Вертикальная 720x1280, Яндекс Игры, только веб.
2. **Геймплей** — merge-доска, цепочки предметов, генераторы, энергия.
3. **Экономика** — монеты, энергия (регенерация по времени), цены.
4. **Мета (обустройство)** — renovation: постройки/декор дачи, прогресс.
5. **Заказы** — требования на предметы, награда монетами.
6. **Монетизация** — rewarded-реклама, interstitial.
7. **Сохранения** — localStorage + облако Яндекс Игр.
8. **UI/UX** — экраны BOARD и META, HUD, туториал.
9. **Туториал** — обучающая последовательность.
